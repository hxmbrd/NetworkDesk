# NetworkDesk brand assets

- `networkdesk-logo.png`: transparent horizontal logo.
- `networkdesk-header.png`: opaque light-background version for README display in light and dark themes.

Created for this project on 2026-11-27 with OpenAI's built-in image-generation tool. The mark depicts a network-node N beside the NetworkDesk wordmark. No third-party reference logo or stock asset was supplied. These are raster PNGs, not vector masters. Visual review checked spelling and legibility; no trademark clearance is claimed.

These assets are included with the GPL-3.0-only project distribution. This statement does not assert exclusive rights in AI-generated elements or grant rights to third-party trademarks.

## Generation prompt

Use case: logo-brand. Create a polished professional logo for NetworkDesk, a network infrastructure visualization and monitoring software project. One horizontal logo lockup: a distinctive compact geometric network-node monogram suggesting the letter N, beside the exact word 'NetworkDesk'. Crisp flat vector-like design, balanced custom sans-serif typography, highly legible at small sizes. Deep navy wordmark and restrained teal/cyan network mark. True transparent background, generous padding. No tagline, no gradients, no shadows, no 3D, no mockups, no extra text, no existing brand logos. This is a production asset for a GitHub README.

## Header adaptation

The generated logo was passed back to the same tool with an instruction to preserve the mark, typography, spelling, colors and layout while replacing transparency with a solid white background and retaining clear padding.
